# 🌿 Synthèse de Stage – STIBOIS

## 📌 Description

Ce projet est un site web présentant la synthèse de mon stage effectué chez **STIBOIS**, filiale du groupe Poulina, au sein du département finance durant l’année 2025–2026.

## 🎯 Objectif

Mettre en valeur mon expérience professionnelle à travers une interface web moderne, claire et structurée.

## 🏢 Entreprise

**STIBOIS – Groupe Poulina**
Entreprise spécialisée dans les dérivés du bois (MDF, contreplaqué, etc.), reconnue pour son professionnalisme et son efficacité.

## 💼 Missions réalisées

* Préparation et suivi des règlements
* Gestion de la trésorerie
* Suivi des opérations bancaires
* Utilisation des systèmes internes (QAD, MFG-PRO, FRP)

## 🛠️ Technologies utilisées

* HTML5
* CSS3

## 🌐 Aperçu du site

Le site présente :

* Une introduction (hero section)
* Une présentation de l’entreprise
* L’organisation et les activités
* Le déroulement du stage
* Les missions et observations
